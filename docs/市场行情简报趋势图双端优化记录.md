# 市场行情简报趋势图双端优化记录

## 业务口径

- 价格沿用采价复核后的周均价，库存沿用周末库存或月内周片段的期末库存。
- 不把周均价拆成每日价格，也不补造日级波动。
- 周报只有一个完整周，月报包含自然月内的周或跨月周片段。

## 展示调整

- 周报不再绘制空旷的单点折线图，改为“本周平均价格”和“周末库存”两个单周指标卡，直接显示期间与数值。
- 月报继续按月内周或周片段绘制价格、库存趋势，图表随容器宽度自适应，纵轴使用规整刻度和千分位格式。
- 月报趋势点支持悬停、点击及方向键查看完整周片段日期与数值；折叠区展开后再按实际宽度绘制。
- 明细统一命名为“周度量价明细”，价格字段统一为“周均价”。

## 双端同步

- 管理端简报详情、编辑/复核参考栏和版本详情复用同一展示组件。
- 小程序端市场行情列表详情及经营报告引用行情复用同一展示组件和业务口径。
- 管理端或小程序任一端后续优化，只要涉及双端共享或对应的数据、文案、状态、交互或展示，均同步检查并修改另一端；端特有布局继续使用各自已有组件适配。

## 保持项

- 不修改周均采价维护入口、数据来源、报告期间、复核发布、版本历史和商户隔离规则。
- 不清空或覆盖已有缓存；旧版与新生成内容均直接使用原有周度序列展示。

## 检查范围

- 更新图表专项检查，覆盖周报单周指标、月报周片段趋势、自适应宽度、数值提示和键盘交互。
- 重建并校验小程序独立发布快照，确保只投影管理端真实已发布版本。
- 本次仅执行静态和 Node 检查，未进行浏览器渲染验收。
