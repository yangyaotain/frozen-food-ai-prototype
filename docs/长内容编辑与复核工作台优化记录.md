# 长内容编辑与复核工作台优化记录

## 本次范围

用户确认将以下六个长内容任务从弹窗改为当前管理模块内的二级工作台：

- 行业资讯展示稿编辑；
- 市场行情简报编辑；
- 商户经营报告与建议编辑；
- 行业资讯详情与核验；
- 市场行情简报复核；
- 商户经营报告与建议共同复核。

发布确认、标记异常确认、来源与采价等短表单、非待核验资讯详情及其他页面保持原实现。本次不改变数据、版本、快照、复核发布门槛、商户隔离或商户端展示。

## 页面组织

公共`assets/js/ui.js:openTaskWorkspace`隐藏当前列表根节点并在同一`page-body`中挂载工作台。列表DOM不重建，因此原页签、查询条件、已执行筛选、分页和表格内容保持；关闭后恢复进入前的页面滚动位置与触发按钮焦点。打开工作台写入history state，浏览器返回可回到列表；表单输入变化后，返回、外部导航或关闭页面会提示未保存内容。

工作台复用项目颜色、字体、间距、圆角、阴影和按钮。顶部展示返回入口、任务标题、版本状态与紧凑元数据；底部固定取消和主操作。桌面主区用于正文编辑或全文阅读，侧栏用于原文、保存前数据依据或复核表单；1180px以下改为单列。公共文本域仍为96px，只有工作台按内容语义使用摘要、正文、建议和文章四档初始高度，并允许垂直调整；带`maxlength`的文本域显示当前字数。

资讯编辑采用原文留档与展示稿并列；资讯核验将原文和待核验展示稿同时显示。简报、报告编辑侧栏复用现有正文渲染器展示保存前内容和数据依据。复核页直接展开完整正文，结论、逐项确认与意见固定在侧栏，不再通过折叠区进入。

## 变更文件

- `assets/js/ui.js`：公共工作台、历史返回、未保存保护和文本域计数；
- `assets/js/shell.js`：路由切换时清理工作台监听；
- `assets/css/common.css`：工作台布局、固定头尾、侧栏、对照区和长文本高度；
- `assets/js/admin-news.js`：资讯展示稿编辑；
- `assets/js/admin-sources.js`：待核验资讯详情与核验；
- `assets/js/admin-bulletins.js`：简报编辑与复核；
- `assets/js/admin-reports.js`：报告与建议编辑、共同复核；
- `scripts/check-edit-workspaces.mjs`：本次静态结构检查。

## 检查边界

已执行全项目静态检查，以及来源、资讯、简报、报告、追溯和工作台专项Node检查。检查覆盖脚本语法、资源路径、UTF-8、基础CSS、原业务数据门槛、工作台接入、响应式结构、文本区高度、历史返回及未保存保护代码存在性。

本次按项目约定未启动服务、未打开浏览器；实际视觉比例、sticky效果、滚动手感、浏览器返回及焦点行为仍未做浏览器交互验收。

2026-09-11交互修正：列表根节点`.content-stack`的`display:grid`会覆盖浏览器对`hidden`属性的默认隐藏样式，导致编辑工作台显示在列表下方。公共工作台现在为被替换的列表增加专用标记，并通过限定选择器强制隐藏；退出工作台时同时恢复列表并移除标记。专项检查已增加该显示规则及打开、关闭状态断言。

2026-09-11编辑布局补充：针对用户反馈的左下方空白，三处编辑入口显式使用`mode: 'edit'`。桌面列宽调整为1.6:1，编辑主区决定行高，参考栏使用尺寸包含并在栏内滚动，避免参考全文撑出左栏空白；编辑工作台取消整页最小高度的额外撑高。摘要初始120px，分析正文按视口在360–640px之间分配，建议与文章在400–680px之间分配，均保留手动垂直调整。1180px以下切换单列并解除参考栏尺寸包含，完整显示参考内容。此补充替代上文三处编辑沿用四档固定高度及参考栏sticky的描述，复核布局不变；仍按项目约定仅做静态检查。
