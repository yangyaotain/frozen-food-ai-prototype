# 市场量价分析周月维度优化记录

2026-09-14，用户确认取消市场量价分析页面的“本周 / 近4周 / 近8周”查询范围，与行情简报、经营报告统一采用完整周、自然月分析。

## 查询与交互

- 沿用 `admin:analysis` 路由，复用公共 `section-tabs`，页签为“周分析 / 月分析”，默认周分析。
- 周分析使用公共可搜索选择器，选项和选中值均显示周一至周日完整日期；月份使用年月选择控件。查询仅保留对应期间、分析品类和图标加文字的重置按钮。
- 周默认2026-08-24至2026-08-30，月默认2026年7月，初始品类均为鸡副；这两组量价及比较指标数据完整。资讯严格按期间、品类及核验条件筛选，没有匹配内容时保留真实空状态，不新增资讯样例。
- 周、月分别保留期间和品类，切换不重置另一页签；重置只恢复当前页签默认值。
- 选择或清空立即查询。清空期间展示补选提示，清空品类为全部品类。公共查询清空组件补充 `month` 控件支持，未改文字条件的提交规则。
- 页签支持左右方向键、Home/End，使用 `aria-selected`、`tabindex` 和对应 `tabpanel`；隐藏字段的样式只限定本页。

## 分析口径

- 周指标为周均价、周入库量、周出库量和周末库存；环比为上周，同比为上年对应ISO周。上年无第53周或比较数据不足时不强算。
- 月指标为月均价、月入库量、月出库量和月末库存；环比为上一自然月，同比为上年同月。按自然月边界处理28/29/30/31天，库存不按片段累加。
- 本页复用 `periodInsights.collect` 和行情简报的已复核周数据：周均价按周片段在月内覆盖天数加权，周数量按月界折算，使相同品类、相同月份与行情简报指标一致；不另建按4周近似的月度统计。
- 全部品类的月数量由各品类周片段分别统计后求和，价格不跨品类平均。原周采价的复核要求保留。
- 本页周分析保留指标、对照及本周明细，取消单点空旷折线图；月分析按月内周片段展示均价、数量和库存，标清完整片段日期、天数及首尾非整周情况。
- 月内明细先展示实际纳入的统计片段；页内“明细与依据”另外明确原始完整周期间，避免把整周业务数量误当作当月纳入数量。
- AI库存与供需参考使用相同本期、上期汇总，月累计提示天数差异；异常检查继续采用原整周阈值，明确跨月周包含月外日期，不冒充月环比。月度历史季节对照采用完整自然月，不再套用按周起始月份分组的均值。

## 兼容与范围

`analysisStore.query({kind, date, category})` 为新的周/月查询入口；旧 `{end, count, category}` 仍供历史报告和兼容接口使用。查询沿用原会话读取限制，不改变原周数量、采价状态、复核发布、调度配置或已保存报告/版本/缓存。本任务不重建商户快照、不提交Git、不部署。
