# 市场行情与经营内容双端深化记录

## 2026-09-14确认范围

本轮针对小程序市场行情、经营报告和经营建议的内容层级及已发布样例数量进行深化，并同步调整管理端维护入口。沿用原路由、周报/月报筛选、生成计划、页内编辑与复核工作台、发布限制、版本历史和商户隔离，不新增独立建议发布流程，不重做原有图表、量价明细和来源依据。

## 内容结构

- 市场行情在市场摘要与详细量价内容之间增加2–4条“本期重点”。管理端可逐条维护，保存后重新待复核；小程序最新卡片显示前两条，详情显示完整重点。
- 经营报告在经营概要后增加2–4条“经营结论”，用于概括周转、库存结构和出库变化。小程序报告卡片显示关键结论，详情继续保留库存、周转、品类结构、同期对照、市场参照及采价依据。
- 经营建议增加独立“建议摘要”和2–4条“重点关注事项”，原分品类建议正文、量化依据、市场背景与适用边界继续保留。小程序列表不再直接截取整篇建议正文，详情按建议摘要、重点关注事项、分品类建议与依据展开。
- 报告与建议仍属于同一记录和同一版本，在原管理端工作台共同保存、共同复核、共同发布；任一文字变化后共同重新待复核。

旧管理端缓存缺少新增字段时，根据该版本冻结的数据快照补充结构化摘要，不覆盖原报告正文、业务状态、人员、版本、复核和发布记录。新增字段随后按正常编辑和版本规则维护。

## 已发布投影

独立小程序仍由`scripts/merchant-demo-source.mjs`读取管理端默认状态中的真实已发布投影，并通过`scripts/build-merchant-demo.mjs`整体重建公共及三户快照：

| 内容 | 当前已发布投影 |
| --- | --- |
| 市场行情 | 5份：3份周报、2份月报 |
| 行业资讯 | 9篇：政策信息2篇、行业资讯3篇、供需行情4篇 |
| 丰茂冻品商行 | 4份报告及同版建议：2份周报、2份月报 |
| 润泽水产商行 | 4份报告及同版建议：2份周报、2份月报 |
| 锦禾食品商行 | 4份报告及同版建议：2份周报、2份月报 |

新增行情与报告只选择通过现有数据质量和发布检查的历史期间。2026年6月、7月等受当前市场参与度检查限制的内容继续保留原状态，没有为增加数量而绕过发布限制；原待复核、需修改、待发布和已发布状态仍在管理端四个报告Tab首屏覆盖。新版待复核时，小程序继续展示同内容旧已发布版。

## 检查范围

- 脚本语法及新增字段校验。
- 行情、报告和建议编辑、复核、发布、修订及缓存恢复。
- 公共行情5份、三户各4份报告/建议的管理端与独立快照逐字段一致性。
- 小程序摘要、重点、完整详情、周/月筛选、触底追加、同版报告/建议互跳和商户隔离。
- 全项目静态检查及`git diff --check`。

`node scripts/check.mjs`通过，131个文件及14个路由的语法、资源路径、UTF-8和基础样式检查正常；28项专项脚本中25项通过。其余3项仍为既有旧断言：`check-deepening.mjs`仍按早期3种周转天数判断当前完整样例，`check-generation-schedule.mjs`把页面打开后的执行时间固定为09:00，`check-review-round.mjs`的旧缓存迁移场景仍假定管理端初始化后没有任何已发布投影。这三项并非本轮字段、双端投影或交互回归失败。
