## 关键操作与保存规则

1. **重新生成**：从简报或经营报告列表的“重新生成”进入，确认当前对象、期间及将创建的V+1，按最新数据生成。可以从待复核、退回、已复核或已发布的最新版本发起。全部旧版本留档；只有新版本可以继续处理。新版本须重新复核、单独发布，不能继承旧通过结论。失败不产生半成品。维护员或综合演示角色可操作。
2. **修订文字**：仅在最新已发布版上操作，沿用原数据；适用于文字调整，不用于修复旧数据检查缺失。旧版缺P2检查时应改用“重新生成”，不用改变业务期间或清空缓存。
3. **资讯核验**：先整理处理方式、展示正文和有效依据，再由复核员核对。未解决问题应核验不通过。前端检查针对已知演示问题，不是通用自然语言事实核验器；审核责任通过明确的正文对照与确认项呈现。人工改稿会清除原文附带的方向判定元数据，避免新正文沿用旧解释。
4. **数量口径**：市场原周数量先按品类归并，自然月按周覆盖日采用，舍入余数归周日；不对每条原始名称先拆日再求和，避免舍入口径不同。本户原周明细同时区分本期、环比基期和商户ID。
5. **月度对照与隐私**：上月为紧邻完整自然月，同比为上年同月；月累计受天数影响，页面明确说明。当前月及其对照期间共同检查发布范围。例：2026-07月报引用受限的2026-06基期，整份月报限制发布，不能通过比较表或文字反推受限量。
6. **来源解释**：逐条使用信息ID定位背景。info-7提供2026-08-24至08-30鸡副出库方向的虚构来源示例，可与同期间数据交叉核对。来源与指标方向不一致时提示核对口径；期间不同、缺基期或定性背景不判一致性。资讯既不自动证明因果，也不直接生成采购、定价或利润结论。
7. **公开边界**：商户只接收已准许的公开数据及本户内容；Q3原始数量、内部处理依据和月度基期原始行不传递。可见性消息只包含是否存在未发布、旧版待检查、受限内容的通用标志，不包含受限标题、商户、品类、金额或数量。
