# 行业资讯双端内容深化记录

## 2026-09-14确认范围

本轮同时深化管理端“行业资讯”和小程序“行业资讯”，不在小程序单独硬编码额外内容。资讯继续经过来源确认、逐篇整理、核验和人工发布，再由独立小程序快照读取管理端默认状态中的真实已发布版本。

保留来源管理与定期获取、三类资讯归属、适用品类、有效期、历史版本、暂停展示和重新发布规则；不增加收藏、分享、评论、阅读量、封面轮播、推荐算法、推送或新的管理菜单。不恢复已移除的小程序资讯预览入口，不修改登录、五项导航、行情简报、经营报告及商户隔离。

## 内容模型

管理端展示稿及发布快照在原标题、正文、分类、品类、来源、有效期和版本之外，增加：

- 内容摘要：20–200字，用于管理列表及小程序列表、详情导语。
- 核心要点：2–4条，每条不超过100字；小程序最新资讯卡片展示前两条，详情展示全部。
- 关注事项：20–300字，说明适用边界、需继续核对的事项或不能直接推导的结论。
- 发布正文：继续使用纯文本短标题及空行分节，不引入富文本编辑器。

旧发布缓存没有新增字段时继续兼容读取：摘要可从原正文生成，要点和关注事项按可用字段展示；新生成的管理端发布投影必须包含完整结构化字段。

## 管理端调整

- 资讯列表使用内容摘要，不再截取正文首行。
- 查询关键词覆盖标题、摘要、核心要点和来源。
- 展示稿页内工作台增加摘要、核心要点和关注事项，并对数量及长度进行校验。
- 详情与核验继续对照原文和展示稿，展示稿侧按摘要、要点、正文、关注事项分层；核验确认项同步覆盖新增字段。
- 发布确认显示摘要和核心要点，但不在短确认弹窗重复整篇正文。
- 已发布内容修改后仍暂停当前版本并进入待核验；重新核验和发布前，小程序只保留上一已发布快照。

## 小程序调整

- 资讯首条复用现有强调卡片，标记“最新发布”，展示摘要及前两条核心要点；其他卡片保持紧凑，仅展示摘要、来源、日期和品类。
- 详情按资讯摘要、核心要点、资讯正文、关注事项、来源与核验发布信息连续阅读；来源与版本信息继续折叠。
- 搜索覆盖标题、摘要、核心要点和来源；分类、品类筛选及空状态保持原交互。
- 下拉刷新、触底加载、详情返回位置、折叠状态及新版提示规则不变。

## 发布样例与投影

管理端仍为26条资讯，默认状态调整为9篇已发布、7篇待发布、1篇暂停展示和9篇未发布。其中已发布资讯为政策信息2篇、行业资讯3篇、供需行情4篇；新增发布内容来自原有已核验待发布资讯，不改变原始来源范围。未按12个品类机械补齐，未命中的品类继续显示真实空状态。

该阶段由`build-merchant-demo.mjs`整体重建公共及三户快照，公共快照保持3份行情，资讯更新为9篇；丰茂、润泽、锦禾分别为3、2、2份报告及同版建议，报告冻结内容没有因资讯展示优化回写。后续行情及经营内容数量由`市场行情与经营内容双端深化记录.md`更新。
