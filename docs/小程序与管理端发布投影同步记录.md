# 小程序与管理端发布投影同步记录

## 2026-09-11确认范围

独立小程序继续使用隔离的静态发布快照，不直接加载管理端采价、映射、来源、报告、用户或追溯仓库。本轮只同步管理端默认状态中真实存在的已发布投影，不修改小程序登录、五项导航、筛选、下拉刷新、触底加载、详情返回、本户隔离和移动端布局。

管理端的待复核、需修改、待发布和执行记录不进入小程序；同一内容存在新版待复核时，小程序继续展示原已发布版本。此前独立构建时自行复核、发布额外内容，以及只重建报告而保留旧公共行情/资讯的方式停止使用。

## 构建与防回退

- `scripts/merchant-demo-source.mjs`在隔离Node上下文中加载管理端默认状态，并只读取`bulletinStore.published()`、`sourceStore.newsPublished()`和`reportStore.publishedFor(merchantId)`。
- `scripts/build-merchant-demo.mjs`始终同时重建`public.js`及三户报告快照，不再支持`--reports-only`的局部重建方式，也不再把业务人员覆盖成“复核员／发布员”。
- `scripts/check-merchant-parity.mjs`逐字段比较独立快照与管理端默认已发布投影，覆盖商品名称、国产/进口、采价、来源、正文、人员、版本及草稿隔离。
- 原小程序移动结构、交互、全品类行情筛选、本户报告校验和界面文案检查继续保留。行业资讯仅对当前已发布文章覆盖的品类返回结果；本次从管理端现有已核验内容中按业务代表性补充至9篇，不机械填满12类筛选。
